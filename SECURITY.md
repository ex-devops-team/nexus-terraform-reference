# Политика безопасности

Не создавайте публичный Issue с credentials, внутренними URL, Terraform state
или чувствительными фрагментами plan. Используйте private vulnerability
reporting GitHub, если он доступен для репозитория, либо свяжитесь с владельцами
организации через закрытый канал.

Публичные примеры используют только placeholder-значения. Перед публикацией PR
проверьте его Gitleaks и убедитесь, что plan/state не добавлены в Git.

Репозиторий является reference implementation и не предоставляет SLA или
гарантию пригодности конфигурации для production.
